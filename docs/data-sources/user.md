# mistershell_user (Data Source)

Reads a MisterShell user. Look up by id for a direct fetch, or by email (exact match, must resolve to exactly one user).

## Example Usage

```terraform
# Look up a user by ID.
data "mistershell_user" "by_id" {
  id = 123
}

# Look up a user by email (must match exactly one user).
data "mistershell_user" "by_email" {
  email = "alice@example.com"
}
```

# mistershell_auth_provider_mapping (Data Source)

Reads an external group to role mapping under an authentication provider. Specify provider_id and either id or an exact external_group.

```hcl
data "mistershell_auth_provider_mapping" "engineering" {
  provider_id    = mistershell_auth_provider.corporate.id
  external_group = "engineering"
}
```

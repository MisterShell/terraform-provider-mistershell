# mistershell_external_vault (Data Source)

Reads an external vault by ID or exact name/mnemonic. Exposes masked configuration and metadata only; no checks, authentication or secret resolution are performed.

## Example Usage

```terraform
data "mistershell_external_vault" "production" {
  mnemonic = "production-vault"
  # Alternatively use id = 42 or name = "Production Vault".
}

output "vault_type" {
  value = data.mistershell_external_vault.production.vault_type
}
```

- `is_enabled` (Boolean) Whether the vault is enabled.
- `last_check_at` (String) Last check timestamp; Terraform never initiates checks.
- `last_check_error` (String) Last check error.
- `last_check_status` (String) Last check status.
- `updated_at` (String) Last update timestamp.
- `vault_type` (String) Vault provider type.

Lookup by ID or exact name/mnemonic. Missing or ambiguous matches produce an
error. `config` contains the API's masked secret values (`****`), not usable
credentials; do not feed it into a new vault resource as secret configuration.
Reads return metadata only and do not authenticate to the vault or resolve secrets.

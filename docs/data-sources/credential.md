# mistershell_credential (Data Source)

Reads a MisterShell credential. Look up by id for a direct fetch, or use name/credential_type to search. Search filters must match exactly one credential. Note: secret fields in credential_data are masked as '****' by the API.

## Example Usage

```terraform
# Look up by ID
data "mistershell_credential" "by_id" {
  id = 1
}

# Look up by unique name
data "mistershell_credential" "by_name" {
  name = "dc-admin-ssh"
}

# Look up by type (must match exactly one)
data "mistershell_credential" "k8s" {
  credential_type = "kubeconfig"
}
```

## Runtime credential types

`credential_type` values are supplied by the target MisterShell instance.
Query `GET /api/v1/credentials/types` for the
current catalog and JSON Schemas; installed extensions may add types.

## External sources

Both platform and user sources expose their vault IDs, names, types, and reference
metadata. Literal secret fields are masked as `****`; external mapped values are
not fetched. This data source cannot provide resolved credentials to other
providers. Name lookup fetches full detail, just like ID lookup.

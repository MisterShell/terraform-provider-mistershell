# mistershell_sensor_rule_override (Data Source)

Reads the staged override and default state of a sensor catalog rule. A null action means no override. Effective state includes staged changes and does not confirm sensor deployment.

## Example Usage

```terraform
data "mistershell_sensor_rule_override" "rule" {
  gid = 1
  sid = 2024218
}

output "rule_change_pending" {
  value = data.mistershell_sensor_rule_override.rule.pending
}
```

`action` is `enable`, `disable`, or null when no override exists. `pending`
compares the stored override with the active ruleset snapshot.
`effective_enabled` reflects staged configuration; it does not prove that any
sensor has downloaded or activated that configuration.

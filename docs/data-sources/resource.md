# mistershell_resource (Data Source)

Reads a MisterShell network resource. Look up by id or search by name/resource_type/location_id/status. The engine is resolved from the target instance's installed type catalog.

## Example Usage

```terraform
# Look up by ID
data "mistershell_resource" "by_id" {
  id = 1
}

# Look up by name
data "mistershell_resource" "by_name" {
  name = "core-sw-01.zurich"
}

# Look up by name + type (narrows search)
data "mistershell_resource" "switch" {
  name          = "core-sw-01.zurich"
  resource_type = "cisco_iosxe"
}

# Access discovered metadata
output "switch_extra_data" {
  value = data.mistershell_resource.by_id.extra_data
}

# The live tags assigned to the resource (computed read-back): a list of
# objects { id, name, color, description }.
output "switch_tags" {
  value = data.mistershell_resource.by_id.tags
}
```

## Runtime resource types

`resource_type` values are supplied by the target MisterShell instance;
installed extensions may add types. Query
`GET /api/v1/resources/types` for the current type and engine catalog. The
computed `engine_id` is resolved from that catalog. `external_id` can be null,
including for a valid Generic SSH target.

The computed `tags` list always reflects the live assignments for the matched
resource. To list or search all tags, use the `mistershell_tags` data source.

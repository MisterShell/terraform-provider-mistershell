# mistershell_user_role (Resource)

Assigns one MisterShell role to one user. (user_id, role_id) is unique. Both fields force replacement on change. Import format is "<user_id>:<role_id>".

## Example Usage

```terraform
# Assign the "auditor" role to Alice. Role assignments are managed exclusively
# through this edge resource; mistershell_user exposes assigned roles read-only.
resource "mistershell_user_role" "alice_auditor" {
  user_id = mistershell_user.alice.id
  role_id = mistershell_role.auditor.id
}
```

this resource; the `mistershell_user` resource and data source expose assigned
roles read-only via their `roles` attribute.

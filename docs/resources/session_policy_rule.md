# mistershell_session_policy_rule (Resource)

Manages a MisterShell session-policy rule. Rules form an ordered chain evaluated by position (lower runs first). Set distinct positions for deterministic order. Empty selector sets mean "Any"; the last remaining rule cannot be deleted.

## Example Usage

```terraform
# A deny rule placed early in the chain. Lower position runs first; assign
# distinct values (e.g. 10, 20, 30) for deterministic ordering.
resource "mistershell_session_policy_rule" "deny_dangerous" {
  name     = "deny-dangerous-shell"
  position = 10
  action   = "deny"

  session_types   = ["shell"]
  resource_types  = ["linux", "generic_ssh"]
  command_acl_ids = [mistershell_session_policy_acl.dangerous_commands.id]

  notify = true
  log    = true
}

# A broad accept rule placed later (lower priority). Empty selector sets
# (resource_types, session_types, etc.) mean "Any".
resource "mistershell_session_policy_rule" "allow_rest" {
  name     = "allow-everything-else"
  position = 20
  action   = "accept"
}
```

### Optional

- `action` (String) Rule action. One of: accept, deny. Defaults to accept.
- `command_acl_ids` (Set of Number) Command ACL IDs referenced by this rule. Empty set means Any.
- `comment` (String) Optional free-form comment.
- `enabled` (Boolean) Whether the rule is enabled. Defaults to true.
- `location_ids` (Set of Number) Location IDs this rule applies to. Empty set means Any.
- `log` (Boolean) Whether to log on match. Defaults to false.
- `name` (String) Rule name (up to 128 characters). Defaults to empty. Not required to be unique.
- `notify` (Boolean) Whether to notify on match. Defaults to false.
- `position` (Number) 1-based evaluation position (lower runs first). Omit to append at the end (server uses max+10). Assign distinct values for deterministic ordering; ties break by id. Set declaratively (the provider never calls the reorder endpoint).
- `resource_types` (Set of String) Resource types this rule applies to. Empty set means Any. Values are inventory resource-type strings.
- `role_ids` (Set of Number) Role IDs this rule applies to. Empty set means Any.
- `session_types` (Set of String) Session types this rule applies to. Empty set means Any. One of: shell, graphical.
- `tag_ids` (Set of Number) Tag IDs this rule applies to. Empty set means Any.

- `hit_count` (Number) Number of times this rule has matched (runtime telemetry, read-only).
- `id` (Number) Rule ID.
- `last_hit_at` (String) Timestamp of the last match (runtime telemetry, read-only).

## Matching and order

Empty match sets mean “any.” `session_types` accepts `shell` and `graphical`.
`resource_types` uses the live RDK catalog returned by
`GET /api/v1/resources/types`, so installed extensions are supported.

Rules are evaluated by ascending `position`. Omit `position` to append using the
server-assigned value, or use distinct values such as 10, 20, and 30 for stable
ordering. The provider updates `position` directly with PATCH. `hit_count` and
`last_hit_at` are read-only runtime telemetry. MisterShell refuses to delete the
last remaining rule.

## Import

Import is supported using the following syntax:

```shell
# Session-policy rules are imported by their integer ID.
# Note: the last remaining rule cannot be deleted (the rule chain is never
# emptied); edit it instead of destroying it.
terraform import mistershell_session_policy_rule.deny_dangerous 7
```

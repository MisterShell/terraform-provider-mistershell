# mistershell_tree_element (Resource)

Manages a MisterShell tree_element. Requires the corresponding read, write and delete API permissions. Read uses the scoped browse tree. Missing entries fail refresh because scope loss and deletion are indistinguishable. Import the numeric element ID.

Requires MisterShell >= 2.1.0.

## Example Usage

```terraform
resource "mistershell_tree_element" "example" {
  parent_key   = "location:2"
  element_type = "label"
  label        = "Production"
  config = {
    icon    = "shield"
    color   = "warning"
    variant = "badge"
  }
}
```

All configuration keys are optional. Pass a native Terraform object, without
`jsonencode`. Omitted configuration is null; label elements render as badges
when no variant is selected. Elements are presentation only: they contain no
resources and grant no access. The provider manages type, parent, label and
configuration; sibling ordering is not owned.

Requires `app.resources.read` for the scoped browse tree, plus
`app.resources.write` and `app.resources.delete` for resource management on the
parent location. Root elements require unrestricted location scope. A missing
entry is an error, because tree filtering cannot distinguish deletion from
lost permission. Restore access, or confirm deletion and remove it from
Terraform state before recreating it.

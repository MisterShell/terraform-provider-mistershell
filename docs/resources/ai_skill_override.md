# mistershell_ai_skill_override (Resource)

Adopts the enabled setting of an existing built-in AI skill. Destroy restores its captured original setting and never deletes the skill. Import captures the current setting as the restoration baseline.

## Example Usage

```terraform
data "mistershell_ai_skill" "builtin" {
  name = "arista-eos-platform-brief"
}

resource "mistershell_ai_skill_override" "builtin" {
  skill_id   = data.mistershell_ai_skill.builtin.id
  is_enabled = false
}
```

## Ownership and restoration

This resource adopts only `is_enabled` on a built-in skill. Name, content and
metadata remain registry-owned. Destroy restores the enabled value captured at
adoption or import; it never deletes the skill. Import cannot recover the value
from before the import. Keep one override per built-in skill.
